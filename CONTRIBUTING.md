# Contributing to NexChat

Thank you for your interest in contributing to NexChat!

## How to contribute

1. Fork the repository.
2. Create a new branch.
3. Make your changes.
4. Test your changes.
5. Commit your changes with a clear message.
6. Push your branch.
7. Open a Pull Request.

## Before submitting

- Make sure existing functionality still works.
- Add tests for important changes.
- Do not commit passwords, API keys, tokens, or `.env` files.
- Follow the existing project structure and coding style.

## Pull Requests

Please explain:
- What was changed
- Why it was changed
- How it was tested if any change you do
